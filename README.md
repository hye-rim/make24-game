# 24 만들기 🧮

네 숫자에 + − × ÷ 를 써서 정확히 24 를 만드는 암산 퍼즐입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: **숫자 카드 → 연산 → 숫자 카드** 순서로 눌러 두 카드를 하나로 합칩니다(세 번 하면 하나가 남음). `↩ 되돌리기` · `⟲ 다시` · `💡 힌트` · `⏭ 건너뛰기`. PC 는 숫자 `1`~`4`(카드 고르기), `+ − * /`, `Backspace` 되돌리기, `R` 다시, `H` 힌트, `N` 건너뛰기, `P` 일시정지, `M` 소리.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 두 카드를 합친 결과는 두 번째로 고른 카드 자리에 놓입니다(예: 8 → ÷ → 3 은 8÷3). **나눗셈은 분수로 정확히** 계산하고(8÷3 = 8/3, 3 − 8/3 = 1/3, 8 ÷ 1/3 = 24), 0 으로는 나눌 수 없습니다. 하나만 남았을 때 24 면 성공, 아니면 값을 알려 주고 되돌릴 수 있습니다.
- 제한 시간 안에 최대한 많은 문제를 풉니다(쉬움 150초, 보통·고수 120초). **건너뛰기** −8~10초, **힌트**(지금 카드 상태에서 이어서 풀 수 있는 다음 한 수를 초록 테두리로 알려 줌) −6~8초. 시간이 다하면 끝, 기록은 **푼 문제 수**(난이도별 저장, 로비는 보통)입니다.
- **난이도**: 「쉬움」 1~9 의 숫자 중 정수만으로 풀리고 서로 다른 풀이가 3개 이상인 문제(316개). 「보통」 1~13 의 숫자 중 정수 계산만으로 풀리는 문제(1346개). 「고수」 분수를 거쳐야만 풀리는 문제(16개, 예: 3 3 8 8 · 1 5 5 5)와, 빼기·나누기를 꼭 써야 하고 풀이가 3가지 이하인 문제(387개).

## 모든 문제가 풀립니다 (검증)
- 문제는 1~13 의 네 숫자 조합 1820개 전부를 풀이 검색으로 분류해 **풀리는 것만** 모아 둔 뒤 그 안에서 뽑습니다(1~13 의 조합 중 풀리는 것은 1362개).
- 시험은 이 풀이 검색을 **독립적으로 다시 적은 소수점 기준 풀이기와 1820개 조합 모두 비교**해 풀림/안 풀림이 하나도 어긋나지 않는지 확인합니다. 또 검색이 찾은 풀이를 실제 `combine()` 으로 그대로 따라 하면 24 가 되는지, 힌트를 계속 따라가면 반드시 풀리는지도 봅니다.
- 처음에 풀이 검색이 남긴 「몇 번째 카드」 번호가 합친 결과를 놓는 자리와 어긋나서, 찾은 풀이를 따라 하면 풀리지 않는 버그가 있었고 고쳤습니다.

## 확인 못 한 것
- **사람이 실제로 한 판에 몇 문제를 푸는지(체감 난이도)** 는 측정하지 못했습니다. 쉬움·보통은 시간 제한이 넉넉한지, 고수는 너무 어렵지 않은지는 해 보셔야 압니다.

## 참고한 것과 제가 정한 값
- 「네 수로 24 를 만드는」 널리 알려진 카드 게임을 따랐고, 시간 · 힌트와 건너뛰기 비용 · 난이도 구분(풀이 개수, 빼기·나누기 필요 여부)은 제가 정한 값입니다. 온라인 대전은 없습니다.
